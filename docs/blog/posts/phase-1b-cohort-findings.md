## Limits

- One measurement per point, except the repeat boots in the table below.
- One GPU provider (RunPod, Secure cloud).
- Multi-GPU execution appears only in the tensor-parallel failure proof.
- No comparison with managed hosting yet.
- The Mamba model has no memory mechanism in the calculator; it is reported
  as unknown, not estimated.
