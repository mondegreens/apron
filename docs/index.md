# Apron

Decision and evidence system for LLM inference deployment.

This site publishes the methodology, contracts, metrics and architecture decision records. The specification is published; implementation has not started.

Start with the [product definition](product-definition.md), then the [target architecture](target-architecture.md) and [phase plan](phase-plan.md). The [framework specification](framework-spec.md) defines the extension points, invariants and metrics. The [architecture decision records](adr/ADR-001-execution-environment.md) record every design decision with its context and consequences.
